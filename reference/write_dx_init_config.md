# Write \`dx_init\` parameters to JSON

Write \`dx_init\` parameters to JSON

## Usage

``` r
write_dx_init_config(path = "ofhelper-config.json", overwrite_existing = FALSE)
```

## Arguments

- path:

  Character string with the name for the JSON file to be written

- overwrite_existing:

  Logical Check if config file already exists and should be overwritten

## Value

Writes a JSON file with the information needed by \[ofhelper::dx_init\]
